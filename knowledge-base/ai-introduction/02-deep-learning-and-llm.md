# 深度学习与大语言模型

## 1. 神经网络基础

### 神经元（Neuron）
```
输入: x₁, x₂, ..., xₙ
权重: w₁, w₂, ..., wₙ
偏置: b
净输入: z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
输出: a = f(z)   — f 为激活函数
```

### 常用激活函数

| 函数 | 公式 | 范围 | 特点 |
|------|------|------|------|
| Sigmoid | 1/(1+e⁻ˣ) | (0,1) | 梯度消失问题 |
| Tanh | (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | (-1,1) | 零中心，仍有梯度消失 |
| ReLU | max(0,x) | [0,+∞) | 计算快，死亡ReLU问题 |
| Leaky ReLU | max(0.01x,x) | (-∞,+∞) | 解决死亡ReLU |
| Softmax | eˣⁱ/Σeˣʲ | (0,1) | 多分类输出层 |

### 反向传播（Backpropagation）
```
前向传播：输入 → 隐藏层 → 输出层 → 计算Loss
反向传播：由链式法则从输出层→输入层逐层计算梯度
权重更新：w := w - α × ∂Loss/∂w

链式法则示例：
∂Loss/∂w₁ = ∂Loss/∂a × ∂a/∂z × ∂z/∂w₁
```

## 2. 卷积神经网络（CNN）

专为图像设计，利用局部感受野和权值共享。

```
输入图像 → 卷积层(特征提取) → 池化层(降维) → 
卷积层 → 池化层 → 全连接层 → Softmax输出

卷积操作：输出尺寸 = (N - F + 2P) / S + 1
N=输入尺寸, F=滤波器尺寸, P=填充, S=步长
```

经典架构：LeNet-5 → AlexNet → VGG → ResNet → EfficientNet

**残差连接（ResNet）**：y = F(x) + x，解决深层网络梯度消失

## 3. 循环神经网络（RNN/LSTM）

处理序列数据（文本、时间序列、语音）。

```
RNN问题：长距离依赖时梯度消失/爆炸

LSTM（长短期记忆）通过门控机制解决：
- 遗忘门 fₜ = σ(Wf·[hₜ₋₁, xₜ] + bf)    — 决定遗忘多少
- 输入门 iₜ = σ(Wi·[hₜ₋₁, xₜ] + bi)    — 决定更新多少
- 输出门 oₜ = σ(Wo·[hₜ₋₁, xₜ] + bo)   — 决定输出多少
- 细胞状态 Cₜ = fₜ⊙Cₜ₋₁ + iₜ⊙tanh(Wc·[hₜ₋₁,xₜ]+bc)
```

## 4. Transformer与大语言模型

### Self-Attention机制
```
Q (Query) = XWQ
K (Key)   = XWK
V (Value) = XWV

Attention(Q,K,V) = Softmax(QKᵀ/√dk) × V

多头注意力：
MultiHead = Concat(head₁,...,headₕ)W°
headᵢ = Attention(QWᵢQ, KWᵢK, VWᵢV)
```

### Transformer架构
```
编码器：N×[多头自注意力 → 加&归一化 → 前馈网络 → 加&归一化]
解码器：N×[掩码多头注意力 → 加&归一化 → 多头交叉注意力 → 加&归一化 → 前馈网络]
```

### 大语言模型（LLM）发展历程
| 模型 | 年份 | 参数量 | 特点 |
|------|------|--------|------|
| GPT-1 | 2018 | 117M | 预训练+微调范式 |
| BERT | 2018 | 340M | 双向编码，MLM预训练 |
| GPT-2 | 2019 | 1.5B | Zero-shot能力 |
| GPT-3 | 2020 | 175B | In-context learning |
| ChatGPT | 2022 | ~175B | RLHF对齐 |
| GPT-4 | 2023 | ~1.8T | 多模态，强推理 |
| DeepSeek-V3 | 2024 | 671B | MoE架构，开源 |

### RLHF（人类反馈强化学习）
```
1. 监督微调（SFT）：在高质量对话数据上微调
2. 奖励模型训练：人类标注偏好数据，训练奖励模型
3. PPO优化：用强化学习最大化奖励模型得分
```

## 5. Prompt Engineering 提示工程

```
零样本（Zero-shot）：直接描述任务
"将以下句子翻译成中文：Hello World"

少样本（Few-shot）：提供几个示例
"正面：电影很好看 → 积极
 负面：服务很差劲 → 消极
 评价：食物一般般 → ?"

思维链（Chain-of-Thought）：逐步推理
"一步步思考：商店有10个苹果，卖掉3个，
又买来5个，现在有几个？
步骤：10-3=7，7+5=12，答案：12个"
```

## 知识点总结
- CNN通过卷积+池化提取图像局部特征，参数共享高效
- LSTM通过门控机制解决RNN梯度消失，适合序列建模
- Transformer的Self-Attention可并行计算，是LLM的基础
- 大语言模型通过RLHF与人类价值观对齐
- Prompt Engineering是使用LLM的重要技能
